Privacy Policy

Last updated: April 28, 2026

This Privacy Policy describes how the M.O.V.E. Fitness application collects, uses, and protects User information. The App is designed with a decentralized architecture prioritizing user privacy.

1. Local Data Storage (Offline-First)

User data (e.g., weight, height, workouts, preferences) is stored exclusively on the User’s device.

  • No remote databases
  • No cloud synchronization
  • No collection of personal data on developer servers

The User is responsible for the security and backup of their data.

2. Artificial Intelligence and Third-Party Services

The App uses services provided by Google LLC (Gemini APIs).

  • Data (text/images) is sent for technical processing
  • Processing is temporary
  • The User consents to sending data to the third-party provider
  • Results are for informational purposes only

The Developer does not store or use this data for marketing or profiling.

3. Health Data (HealthKit / Health Connect)

  • No data selling or sharing
  • No advertising use
  • Data remains on the device

4. Device Permissions

  • Camera – workout scanning
  • Gallery – image selection
  • GPS – activity tracking (local only)

Location data is not transmitted to external servers.

5. Legal Basis

  • Service execution
  • User consent

6. User Rights

  • Access, modify, or delete data
  • Withdraw consent
  • Uninstall the App to remove all data

Users may lodge a complaint under Article 77 of the GDPR.

7. Security

Data is protected by the device’s operating system. The Developer is not responsible for device-level breaches.
